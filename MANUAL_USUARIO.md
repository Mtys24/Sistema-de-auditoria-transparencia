# Manual de Usuario: Sistema de Auditoría de Transparen (Copia)

Este manual ha sido generado automáticamente para ayudarle a utilizar el sistema. Puede encontrar la versión completa con capturas de pantalla integradas en los artefactos de esta conversación.

## Funciones Principales

1.  **Tablero**: Visualice el cumplimiento global.
2.  **Filtros**: Busque tareas por estado, sección o departamento.
3.  **Gestión de Estados**: Actualice si una tarea está completada, incompleta o no disponible.
4.  **Gestión de Departamentos**: Use los botones **"×"** y **"+"** dentro de cada tarea para agregar o quitar departamentos (Municipal, Educación, Salud, etc.).
5.  **Exportación**: Use el botón "Copiar Resumen" para obtener un informe de pendientes.
